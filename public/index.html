Pokémon Price API

A public, read-only JSON web API for pokemon-tcg. Search Pokémon cards by any full or partial name, then retrieve reference prices. Optional search enrichment returns cards and SGD prices together.

OpenAPI 3.1 specification · Integration guide · API health

GET endpointPurpose
/api/market/search?q={name}Matching cards and IDs; existing v1 response.
/api/market/search?q={name}&include=prices&limit=3&page=1Matching cards with SGD prices; opt-in v2, up to six cards per request.
/api/market/cards/{card_id}?currency=SGDSGD prices for any returned card ID. Omit currency for native EUR/USD.
/api/market/ratesDated EUR/USD → SGD exchange rates.

Call from your application

const query = new URLSearchParams({
  q: pokemonName, include: 'prices', limit: '3'
});
const response = await fetch(
  `https://pokemon-price-api-omega.vercel.app/api/market/search?${query}`
);
if (!response.ok) throw new Error(`API error: ${response.status}`);
const result = await response.json();

Names such as Charizard, Eevee and Mew all use the same endpoint. Names must contain 2–60 characters. No API key is required; browser CORS is enabled.

Price availability

HTTP 200 search results may have partial: true when individual prices fail. Inspect pricing.status per card. A successful card with quotes: [] has no available prices; this does not mean a zero price. A real zero is preserved.

Prices: TCGdex / Cardmarket / TCGplayer. Currency conversion: Frankfurter / ECB. Check source timestamps, freshness and FX dates. Search ranks name relevance, not sales popularity. Prices are reference values, not executable offers. Upstream availability and hosting quotas still apply.
